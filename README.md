# Kit de arranque — Backpack Skill

Este kit lleva a Claude Code todo lo que definimos en el chat: producto, seguridad, diseño y plan.

## Cómo usarlo

1. Instala Claude Code (necesita plan Pro, Max, Team o Enterprise): https://code.claude.com/docs/en/quickstart
2. Crea una carpeta para el proyecto, descomprime este kit adentro e inicializa git (`git init`).
3. Abre Claude Code en esa carpeta (`claude`) y pega el contenido de `PROMPT_INICIO.md`.
4. Revisa el plan que te proponga, apruébalo y avanza hito por hito.

## Qué hay aquí

- `CLAUDE.md` — contexto y reglas que Claude Code lee en cada sesión.
- `docs/SPEC.md` — documento de producto del MVP (fuente de verdad).
- `docs/DISENO.md` — dirección visual, colores, tipografías y pantallas.
- `design/prototipo/` — las 4 pantallas del prototipo, como referencia visual.
- `PROMPT_INICIO.md` — el primer mensaje para Claude Code.
